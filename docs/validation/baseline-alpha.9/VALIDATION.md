## 音乐视觉对照

实际共振处理器对同一 16 秒原创 PCM 文件生成特征，两版以完全相同的特征、初始 64,000 粒和固定 1/60 秒步长回放。在 4/8/12/16 秒处，节线附近（空间场平方值小于 0.045）的平均砂粒比例由 46.3% 变为 79.9%。阈值统计与对照截图用于评估指定音乐的形状连贯性；场本身也有变化，不是通用美感分数。

薄板接触更新会改变砂粒轨迹；同一测试中，薄板空间权重的最大差异为 0，绝对激励差异为 0。音乐模式停音后最大平面位移 0，微弱输入最大位移 0。鼓点微光在下一次更新即触发并平滑释放。对照图和原始报告包含在下载包 docs 中。

## 新体验实测

相同 220 Hz 输入从安静到强音，输入 RMS 分别 0.0142 / 0.2953，归一化后画面分析 RMS 为 0.0772 / 0.0807，两次实际播放增益均保持 0.37。自动适配只用于音乐响应，薄板共振保留原始力度。

音乐补砂检查先将 80% 砂粒标记为掉落，推进 10 秒模拟时间。有声音乐且开启补砂时，方/圆板存活比例 enabled: 99.9%，circle: 99.6%；关闭补砂、静音或关闭薄板辅助撒砂均不补回。新砂以渐入方式显示，静音场景的最大平面位移为 0。收藏通过真实关闭和重新启动 exe 的恢复检查，名称以纯文本显示。

原始报告见 docs/experience-report.json，四套预设截图见 docs/preset-*.png。

## 薄板接触、亮度与辅助撒砂

在完全相同初始砂粒和同一原创 PCM 特征下，关闭补砂，方板和圆板各推进 96 秒模拟时间。128×128 统计网格中的最大单格粒数由 square: 2438 → 222，circle: 1425 → 182。每个粒子所在网格的平均粒数由 square: 753.4 → 81.0，circle: 498.8 → 86.8。这是指定音频和网格分辨率下的聚集诊断，不能解释为真实砂粒接触误差或普适美感分数。方板/圆板共振权重及绝对力度均与旧版一致。

直接捕获绘制着色器的亮度输出，极密区域的系数范围 0.850000–0.850000，即最多降低约 15%；稀疏区域输出差异 0。不改全局微光与播放音量。

辅助撒砂是独立、默认开启的外部供砂选项，低于约 90% 砂量才补，约每秒最多补目标数量的 0.8%，接近阈值减速，新砂约 1.2 秒渐入。控制测试从 50% 砂量开始并隔离自然掉砂，60 秒后方/圆板分别为 supply: 88.0%，circle: 88.0%；静音、弱输入、手动演示、关闭辅助和砂量足够时均没有新砂。该功能不修改薄板振动求解；可关闭以观察自然掉砂。原始报告与对照图见 docs/physical-quality-report.json、docs/physical-long-*.png。

## 共振实验室实测

纯音 63.1 Hz 进入分析总线后的 RMS 为 0.07073，FFT 为 63.16 Hz，预期第 3 组模态占比 100.0%。降低播放器音量后，实际监听增益为 0.100，分析 RMS 为 0.07099；增加实验音强度后 RMS 为 0.14107。它与静态手动演示的模拟激励分开。

选择板心后，不能被中心点力激发的方板第 1 组耦合为 0，实际 PCM 模态功率由 2.616e-1 降至 0.000e+0。后台重建点选振型期间约 784 ms 内仍提交 47 帧，重新撒砂调用次数 0。这是一段本机操作采样，不代表所有点位的计算时间。

对数扫频的实时 FFT 与音频时钟目标吻合，单程结束会停止，往返模式连续反向。底图开关使像素变化，砂粒状态最大差异为 0；底图不透明度为 0 或无绝对激励时，与关闭底图的图像一致。补砂速度 0.5× / 2× 的控制测试在 20 秒模拟时间后砂量为 56.7% / 76.4%。原始数据和预览见 docs/lab-report.json、docs/lab-*-preview.png。

## 模型与适用范围

方板、圆板均为自由边缘，各有 64 组共振，分别包含 86 / 122 个弯曲模态，默认由近中心点力激发，可点选调整位置，排除三个刚体模态。方板采用收敛验证的 Rayleigh–Ritz 求解，圆板采用自由边界 Bessel 特征方程。薄板共振采用平均振动加速度；音乐响应的均衡和相干节线含视觉处理。砂粒迁移、阈值和接触仍是经验近似，没有材料参数标定或逐粒碰撞求解。落砂不反射，R 可重新撒砂；手动演示明确使用模拟激励。完整说明见 PHYSICS.md。

播放列表仅在当前会话有效；切换音频输出设备后需要重新监听。未对所有编码、声卡、独占音频及受保护内容做验证。旧版下载包单独保留。

# Chladni Studio 1.0.0-alpha.10

Windows x64 预览版 · 2026-10-25

## 本版更新

修复冰蓝、紫色、银白主题下仍出现琥珀色控件的问题。播放按钮、滑块、开关、强调文字、选中状态、边框、弹窗、振动底图、图例和激振标记统一跟随当前配色；四张配色预览保持各自颜色。收藏恢复及重启恢复同样生效。

本版保留实时系统声音、音乐文件播放器、音乐响应与薄板共振、方/圆板、纯音和扫频实验、点选激振位置、辅助补砂、自定义收藏，以及覆盖任务栏的完整应用全屏。音频、模态和砂粒动力学沿用 alpha.9。

## 下载与启动

- **Windows-x64.zip**：完整便携下载包，包含 EXE、说明、示例音频、验证报告与源码。解压后运行 EXE。
- **Windows-x64.exe**：只下载便携程序，无需安装 Node.js。
- **SHA256SUMS.txt**：以上两个文件的 SHA-256 校验值。
- GitHub 自动附带的 **Source code** 为仓库源码，不含可运行 EXE。

要求 Windows 10 / 11 x64、WebGL 2 与浮点颜色纹理支持。首次运行需解压内置运行时。本预览版未进行代码签名。

## 验证

本版已通过 21 项基础检查、17 项四配色检查、26 项桌面/音频检查、24 项全屏检查和 12 项便携程序检查。同输入与初始砂粒下，与 alpha.9 的完整粒子缓冲差异为 0。更完整的共振及长时间砂粒专项为 alpha.9 基线，详见仓库 VALIDATION.md 和下载包中的报告。

## 模型范围

薄板使用线性自由边缘模态，砂粒使用近似运动、接触和供砂模型；音乐响应包含视觉调校。用于交互可视化，不用于预测真实金属板实验结果。
